# pragents Strategy

## Target problem

Solo agency operators running multiple client projects with coding agents get trapped *in* the business — babysitting agents, manually syncing diverging skill versions across projects, and holding cross-project context in their head. No existing tool gives agents persistent awareness across projects or lets them run autonomously without constant supervision.

## Our approach

Solo agency automation works when agents have persistent shared state and autonomous workflows — the problem isn't agent intelligence, it's agent memory and coordination. The system learns, understands, and evolves alongside the business.

## Who it's for

**Primary:** Solo agency owners — they're hiring pragents to run their agent team autonomously across client projects, maintaining shared context and executing recurring work, so they can focus on strategy and client relationships instead of supervising agents.

## Key metrics

- **Autonomous task completion rate** — % of tasks agents complete without human intervention (self-reported)
- **Active projects per month** — client projects simultaneously active (self-reported)
- **Supervision hours per week** — hours spent monitoring/correcting agents (self-reported)
- **Workflow reuse rate** — how often existing workflows are re-triggered vs. new ones created (pragents DB)

## Tracks

### Autonomous Workflows

Recurring multi-step agent processes — content pipelines, reporting cycles, client deliverables that run without the owner's involvement.

_Why it serves the approach:_ Proves out the autonomous-workflows bet and builds the library of reusable processes that compound over time.

### Office Operations

Email triage, time management, invoice processing, and admin tasks that don't need the owner's attention.

_Why it serves the approach:_ Frees the owner from daily operations and validates that agents can handle unstructured business tasks reliably.

### Agent Memory & Coordination

Persistent shared state, cross-project context, and skill management — the engine that makes the other tracks work.

_Why it serves the approach:_ This *is* the core bet — without persistent memory and coordination, autonomous workflows stay fragile and project-specific.

### Project Management

Cross-project visibility, task orchestration, and a PM agent that keeps all projects moving.

_Why it serves the approach:_ Gives the owner the overview they're currently holding in their head and lets the PM agent act as the cross-project coordinator.
